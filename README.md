## What I'm building now

### [TubeYou](https://github.com/PantoYT/TubeYou)

A YouTube-inspired platform built without a web framework. It includes video
upload and streaming, subscriptions, comments, profiles, search, email
verification, and an algorithmic feed.

`PHP` · `MariaDB` · `Vanilla JavaScript` · `Docker`

[Live demo](https://tubeyou-spvl.onrender.com) · [Source code](https://github.com/PantoYT/TubeYou)
